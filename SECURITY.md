# Security Policy

## Reporting a vulnerability

Use a private channel — do NOT open a public issue for suspected vulnerabilities.

- Primary: open a [private security advisory](https://github.com/VeTwo-dev/Website/security/advisories/new) on this repository.
- Fallback: contact the maintainers via the GitHub organization. (A dedicated `security@vetwo.dev` address from the brief is UNVERIFIED and not listed as confirmed until maintainers approve and test it.)

Please include: affected URL/commit, reproduction steps, and impact. Redact credentials and farm/telemetry data from reports.

## Scope

This policy covers the public website in this repo. Production response timelines are NOT promised here — no 24h/72h commitments until maintainers explicitly approve them.
